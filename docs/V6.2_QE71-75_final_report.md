# QE-71–QE-75: final verification and submission report (V6.1 → V6.2)

No new research was added. V6.1 results are unchanged; only corrections, qualifications and presentation changes were made.

## QE-71 Mathematical verification (performed)
* Propositions 1–3 and Corollaries 1–2: proofs re-read line by line against the code and the numerical checks
  (Prop. 1: 300 adversarial runs incl. variable/out-of-order/burst delays, max ratio 0.98; Prop. 3: 600 synthetic runs, 0
  violations; Prop. 2: identity checked run by run against the simulation).
* **Proposition 3, corrected/clarified:** (i) the deterministic term assumes all audit results are processed; with P pending
  audited defects at the horizon it increases by at most (1−α)P/(qN); (ii) the fixed-score assumption was stronger than needed —
  the proof requires only *predictable* scores (computed before each decision), so retraining on already-received audit
  results is allowed; scores depending on future audits are not.
* **Latency certification:** text now separates the guarantee (AC, Proposition 2 holds) from empirical coverage (EWMA,
  assumption violated).
* **Clopper–Pearson threshold selection:** qualified — the stepwise rule is a fixed-sequence test, valid at the nominal
  level only under exchangeability (learn-then-test, Angelopoulos et al. 2021); no guarantee under drift.
