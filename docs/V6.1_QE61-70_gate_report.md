# QE-61–QE-70 campaign: gate report (V6.0 → V6.1)

**Decision: V6.1 (corrected and verified V6.0), not V7.0.** Every proposition survived independent checks and two were
corrected or tightened; the new results are applied extensions of established methods, not original mathematics. Their
originality is described accordingly in the manuscript.

## Gate 1 — foundation (QE-61, QE-62)
* **Proposition 1: valid.** Proof reconstructed; it never uses arrival order, so it covers variable, out-of-order and bursty
  delays. Constant tightened: γ(M+1) → γ·max(α, (1−α)M). Convergence needs K → ∞ and M/K → 0; with permanently missing
  labels it concerns confirmed defects only. 300 new adversarial runs (variable/out-of-order/burst delays, delays beyond the
  horizon, γ from 0.001 to 5, |θ₀| up to 30): max deviation/bound 0.98 (M+1 form), 0.993 (tightened) — nearly tight, never violated.
* **Proposition 2: assumption corrected.** "Same post-shift outcomes" was insufficient. Required: same deployment runs, deployment
  before the shift, production until rollback, persistent shift, and **same monitoring state at the shift**. Diagnosis of
  EWMA failures: deployment never changed with L and always preceded the shift; failures (14% of runs at L = 4) arise because
  later deployment changes the number of pre-shift batches feeding the chart. Empty and unbounded feasible sets now handled.

## Gate 2 — new mathematics (QE-63, QE-64)
* **Corollary 1 (finite horizon):** |R_T − R_T^conf| ≤ P_T/N_T ≤ P̂_T/(C_T + P̂_T) with P̂_T observable. Elementary.
  **Negative result:** on AOI the observable bound was ≥ 12% at every week end while the actual gap was ≤ 3.4% — valid but uninformative.
* **Corollary 2 (certified latency):** exposure is a nondecreasing bounded function of one scalar, so a one-sided DKW band
  gives simultaneous upper bounds for all delays without multiplicity correction. Established technique, structural use.
  Results: plug-in simultaneous coverage 33–40%, false certification up to 10%; DKW, Hoeffding–Bonferroni and
  empirical-Bernstein–Bonferroni: 100% coverage, 0 false certification (AC and EWMA); DKW least conservative at small n,
  empirical Bernstein at some moderate n; no uniformly best procedure.
* Verdict: supporting applied tools; no strong original theorem.

## Gate 3 — algorithm (QE-65, QE-66)
* **Proposition 3 (audited release):** IPW-weighted online quantile tracking with randomized post-release audits; deterministic
  path bound + Freedman martingale term gives a high-probability bound on slip over **all** defects. Closest prior art:
  intermittent-feedback ACI (Wang, Zecchin and Simeone 2025). Verdict: applied extension. Synthetic check: 0/600 violations.
* **Impossibility:** with q = 0 and no other feedback, slip is not identifiable; empirically slip rose to 14%.
* **AOI results (D = 7, identical scores):** online 3.0%/33% vs static 5.1%/26%, sliding window 5.3–5.4%/34%,
  exponentially weighted 5.9%/36%, Clopper–Pearson window 2.4%/11%. Audits: q = 0.01 unstable (0.9–14.2%);
  q = 0.1–0.2 slip 1.7–4.3%, audits 1.1–6.2% of alarms, net VR 11–30%. Bound held (max ratio 0.20) but wide (17–24%).
* **Not implemented** (disclosed): conformal risk control, learn-then-test, weighted conformal, confidence-sequence risk
  control and official implementations of delayed ACI variants; the comparison uses internally implemented baselines.

## Gate 4 — audits (QE-67, QE-68)
* **SECOM count error fixed:** text reported 627 initial units (rounding) while the code used int(0.4·1567) = 626; 626 + 941 = 1,567.
  Analysis unaffected; unit test added.
* Initial history uses only units before the deployment start; all preprocessing is fitted on training data only.
* C/M/W repeated with three seeds (V6.0); directions stable, significance varies (reported).
* Abstract corrected: SECOM delay effect stated with its wide intervals.
* Selective-feedback replay simulates audits on retrospective labels (all alarms labelled in the dataset) — disclosed.
